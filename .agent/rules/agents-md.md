# Projektkontext

Lies vor jeder Arbeit `AGENTS.md` im Repo-Stammverzeichnis vollständig und
halte dich an die Arbeitsregeln dort (Deutsch antworten, keine Pull Requests
öffnen, vor jedem Push `npm run check` grün, CI minimal halten).

Lies auch die obersten (neuesten) Einträge in `HANDOFF.md` im
Repo-Stammverzeichnis. Füge am Ende der Sitzung einen neuen Eintrag **ganz
oben** ein: was geändert, was offen. Neueste oben, älteste unten.

`docs/` und `.agents/skills/` sind veraltet und beschreiben
die alte Web-Version, nicht den aktuellen Code.
